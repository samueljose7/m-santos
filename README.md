# M. Santos — Vidraçaria e Serralheria

Site estático em HTML, CSS e JavaScript, com todas as imagens incluídas.

## GitHub
Extraia o ZIP e envie index.html, style.css, app.js e a pasta assets para a raiz do repositório. Envie os arquivos extraídos, não o ZIP.

## Visualizar localmente
Abra index.html no navegador.

## GitHub Pages
Em Settings > Pages, selecione Deploy from a branch, branch main e pasta / (root).

## Vercel
Importe o repositório. Use o preset Other, sem comando de build e com o diretório de saída na raiz.

## Alterações
Textos e contatos: index.html. Visual: style.css. Galeria e formulário de WhatsApp: app.js. Imagens: assets/.

O formulário abre o WhatsApp e não precisa de servidor ou banco de dados. Fontes são carregadas do Google Fonts e o mapa do Google Maps.
